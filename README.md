# tjimmy0113/tap

Homebrew tap for [SuperNotch](https://github.com/tjimmy0113/supernotch).

```bash
brew tap tjimmy0113/tap
brew trust tjimmy0113/tap
brew install --cask supernotch
```

Update: `brew upgrade --cask supernotch` · Remove: `brew uninstall --cask supernotch` (add `--zap` to also remove its preferences).

Homebrew 7+ asks you to trust third-party taps once (`brew trust`).
